# Hollow Knight & Silksong Save Parser

这是一个专门用来分析 **空洞骑士** 和 **空洞骑士：丝之歌** 存档文件的网页工具

你只需要打开网页，上传你的游戏存档，即可一键解析你的游戏进度

## 🌟 主要功能

*   **进度分析**：一键查看完成度详情，包括Boss是否已打、护符/工具是否已拿、碎片是否已找、游戏关键物品是否收集等

*   **额外查询**：
    *   🕷️ **猎人日志**：一键查看猎人日志有哪些内容没有解锁和完成
    *   🐛 **解救进度**：可以查看一代幼虫和二代跳蚤的解救进度，标识出哪些已经拯救哪些没有，并附带具体地图位置

*   **存档修改**：
    *   支持修改吉欧、念珠等数据
    *   支持修改部分游戏物品数据
    *   **⚠️ 警告**：修改功能可能会破坏游戏体验或导致存档损坏，请务必在修改前 **备份** 你的原始存档文件！

*   **双游戏支持**：页面顶部按钮一键切换 Hollow Knight / Silksong，使用各自的解析和规则

## 🚀 如何使用

1.  **打开工具**：直接用浏览器打开项目中的 `index.html` 文件
2.  **找到存档**：
    *   复制网页提供的文件夹路径，访问文件夹找到对应的 `.dat` 存档文件即可
    *   存档文件名通常是 `user1.dat` 到 `user4.dat`
3.  **上传分析**：
    *   点击「选择文件」上传你的 `.dat` 存档
    *   点击「解析存档」即可解析你的游戏进度
    *   解析完成后，会在页面下方显示你的游戏进度详情，也可以选择**猎人日志**解析/**解救进度**解析
4.  **修改保存**（可选）：
    *   如果开启了修改功能，改完后点击「导出修改」
    *   把下载下来的新文件覆盖回原来的存档位置（记得先备份原文件！）

## 🛠️ 技术说明

*   纯前端项目（HTML + JS + CSS），所有数据处理都在你的浏览器里完成，不会上传到服务器
*   使用了 `crypto-js` 来处理存档的加密/解密

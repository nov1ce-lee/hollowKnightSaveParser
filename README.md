# 空洞骑士 & 丝之歌 存档分析器 (Hollow Knight & Silksong Save Parser)

这是一个专门用来分析《空洞骑士》和《空洞骑士：丝之歌》存档文件的网页工具

它可以帮你查看两个游戏当前的 **完成度** 到底缺了什么，还能顺手改改存档（比如加点钱、改个数据、解锁工具之类的）

## 🌟 主要功能

*   **进度分析**：一键查看完成度详情，告诉你缺了哪个 Boss 没打、哪个护符/工具没拿、哪个碎片没找到等等
*   **额外查询**：
    *   🕷️ **猎人日志**：一键查看差哪些怪没解锁和完成
    *   🐛 **收集进度**：在 Hollow Knight 中查看幼虫，在 Silksong 中查看跳蚤，附带具体点位图片

*   **存档修改**：
    *   支持修改吉欧、念珠等数据
    *   支持修改部分游戏物品数据
    *   **⚠️ 警告**：修改功能可能会破坏游戏体验或导致存档损坏，请务必在修改前 **备份** 你的原始存档文件！
*   **多游戏支持**：页面顶部按钮一键切换 Hollow Knight / Silksong，使用各自的解析和规则

## 🚀 如何使用

1.  **打开工具**：直接用浏览器打开项目中的 `index.html` 文件
2.  **找到存档**：
    *   Hollow Knight（空洞骑士）的存档路径通常在：
        `C:\Users\你的用户名\AppData\LocalLow\Team Cherry\Hollow Knight`
    *   Silksong（丝之歌）的具体存档路径以后再补充，实际使用时只要找到对应的 `.dat` 存档文件即可
    *   存档文件名通常是 `user1.dat` 到 `user4.dat`
3.  **上传分析**：
    *   点击「选择文件」上传你的 `.dat` 存档
    *   点击「解析存档」，结果立马出来
4.  **修改保存**（可选）：
    *   如果开启了修改功能，改完后点击「导出修改」
    *   把下载下来的新文件覆盖回原来的存档位置（记得先备份原文件！）

## 🛠️ 技术说明

*   纯前端项目（HTML + JS + CSS），所有数据处理都在你的浏览器里完成，不会上传到服务器，安全放心
*   使用了 `crypto-js` 来处理存档的加密/解密
